Framed artwork for the VRChat Penthouse world.
Loaded at runtime by Assets/Penthouse/Udon/ArtDownloader.cs.

Every picture displayed in the world must be committed and pushed here, or its
frame stays blank in VRChat. After adding/swapping a picture: commit, pull --rebase,
push, then run `python Tools/check_art_hosted.py` from the Penthouse project.
